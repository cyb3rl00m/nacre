# Changelog

## 1.0.1 – 2026-10-25
- Renamed the app from Bulwark to **Nacre** (new app ID `io.github.cyb3rl00m.Nacre`, new icon).
- New: "Shut down the computer when the full scan is done" tick box, on the Scan page and while a full scan runs. A 60-second countdown lets you cancel; the tick box resets after each full scan.
- Full and administrator scans with auto-quarantine now quarantine threats inside the same privileged run, so no second password prompt is needed.
